# 🎹 Fabrica de Pian

Site-ul oficial al **Asociației Fabrica de Pian** din Petroșani — mărturia unui proiect care a adus, prin concerte și prin generozitatea oamenilor, un pian de concert, o sală de concerte și un laborator de muzică pentru copiii Secției de Muzică a Școlii Gimnaziale „I.G. Duca”.

🌐 **Site live:** [fabricadepian.github.io](https://fabricadepian.github.io)

---

## Despre proiect

Fabrica de Pian a pornit în 2020 dintr-un gând simplu: copiii din Valea Jiului care studiază muzica merită un instrument pe măsura talentului lor. Fără bani de la stat, doar prin concerte și donații, proiectul a reușit:

- **Pianul de concert Kawai** pentru Secția de Muzică din Petroșani
- **Sala de concerte**, reconstruită de la zero dintr-o magazie ruinată
- **Laboratorul de muzică „Petru Barbăroșie”** (2022), unde se țin orele de teorie, solfegiu, dictare, cor și chitară

Inițiator și președinte al asociației: [Aurelian Epuraș](https://aurelianepuras.github.io) — pianist, compozitor și profesor de pian.

## Tehnologie

Site static, scris de mână în **HTML, CSS și JavaScript** — fără framework-uri, fără bază de date, fără costuri de găzduire. Este publicat gratuit prin **GitHub Pages**, direct din ramura `main`.

## Cum se actualizează

1. Modifici fișierele local (sau direct pe GitHub).
2. Faci commit și push pe ramura `main`.
3. GitHub Pages republică site-ul automat în 1–2 minute.

Pentru a vedea site-ul local înainte de publicare:

```bash
python3 -m http.server 8000
```

apoi deschizi [http://localhost:8000](http://localhost:8000) în browser.
